# Swarmed roadmap

## Step 1: Foundation (done)
Data-driven content registries, main menu, character select, a settings screen with 40+ options
and key rebinding, pause and game over screens, developer mode (overlay, console, hotkeys) and the
sandbox. Performance core: atlas batching, pooled enemies, spatial hash, pre-rendered floor.
Placeholder content: 2 characters, 3 ants, 6 items, 1 stage, 2 AI behaviours, 2 attacks.

## Step 2: Core loop (next)
Design first, then build:
- Run structure: wave length, wave count, what ends a run (survive N waves? boss?).
- Economy: ants drop nectar (XP + currency), pickup range, level-ups with stat choices.
- Shop between waves: item offers by rarity and wave, rerolls, locking, item limit or none.
- Horde-clearing feel: hitstop on big hits, knockback chains, KO milestones (100, 500, 1000),
  combo rewards, a "musou" style special meter that fills from KOs.
- Weapons: one attack per character, or multiple weapon slots like Brotato?

## Step 3: Content design
- Arthropod roster: beetles, spiders, scorpions, mantis, centipede, crabs/isopods...
  each with a distinct attack pattern and stat identity.
- Ant castes: workers, soldiers, fire ants, bullet ants, flying alates, carriers, acid shooters...
- Item pool: stat trades, conditional items, proc items, synergy tags.
- Bosses (queen guard, the Queen), run events (swarm surge, rain, anteater), new stages.

## Step 4: Polish
Real pixel art and animations, music and sound, juice pass, controller UX, and a performance pass
targeting 1000+ enemies on low-end machines.
